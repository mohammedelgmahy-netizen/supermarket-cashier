# كاشير السوبر ماركت

برنامج كاشير لسوبر ماركت بالعربي يشتغل من المتصفح: بيع بالباركود، فواتير شراء، مخزون، تقارير، ومزامنة مع Supabase.

- اللينك: https://mohammedelgmahy-netizen.github.io/supermarket-cashier/
- تسطيبه كأبلكيشن: افتح اللينك في Chrome، ومن النقط التلاتة ⋮ اختار "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- أول مرة: شغّل `sm_setup.sql` في Supabase (SQL Editor ثم Run).
